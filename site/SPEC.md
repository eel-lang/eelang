# Squeal — лендинг (site/)

Одна статическая страница, которая за первый экран объясняет идею языка и показывает
работающий код вместо обещаний. Документации здесь нет — её пока заменяют `README.md` и спеки.

## Ответственность

- `site/` — лендинг на английском: `index.html`, `style.css`, `script.js`,
  `assets/fonts/` (Archivo и Martian Mono, latin, OFL, self-hosted).
- Открывается двойным кликом и раздаётся любым статик-сервером:
  `python3 -m http.server -d site 8000`.
- Объясняет: синтаксис Python при семантике Gleam/Erlang, шесть правил языка (ядро страницы —
  сетка из шести квадратов), паритет с Gleam, ноутбук, quick start, честный статус первой сборки.

## Границы и ограничения

- **Без сборки и зависимостей.** Никакого node-тулинга и бандлеров: правится как обычный HTML/CSS/JS.
- **Никаких внешних запросов.** Шрифты лежат в `assets/fonts/`, картинок нет (только инлайн-SVG и
  data-URI-фавикон), аналитики нет. Страница работает из офлайна.
- **Никаких выдуманных чисел.** На странице только проверяемые данные: 19 паритет-пар и 104 теста
  (`pytest`), 0 зависимостей (`pyproject.toml`), OTP 29. Бенчмарков, отзывов и «used by» нет —
  сравнивать squeal пока не с чем.
- **Код на странице — настоящий.** Каждый `.ee`-сниппет прогнан через
  `python3.15 -m squeal build`, сгенерированный Erlang скопирован из `build/dev/erlang/<app>/ebin/*.erl`,
  вывод рантайма (`<<"hi">>`, `55`, `#{name => 'Ada', age => 36}`) — из `erl -eval`. При изменении
  языка сниппеты перепроверяются вручную: автоматического теста на них нет (решение пользователя).

## Решения

- **Структура — дизайн-система bun.com.** Announcement bar, sticky-хедер с волосяной линией,
  контейнер в hairline-рамке, hero в две колонки (копия + код-вьюер с табами), полоса BUILT ON
  вместо USED BY, «Six rules» — сетка из шести квадратов (ядро страницы), «A minute with squeal»
  (шаги + терминал), матрица squeal / Gleam / Python, статус, финальный CTA. Меняются тексты и
  графика, не каркас.
- **Палитра — токены bun.com.** Canvas `#fff`, линии `#e2e2e2`, текст `#0a0a0a`, акцент hot pink
  `#ff1f8f` (мелкий текст и ссылки — `#d60066`), бежевая подложка кода `#f8f4ee`. Код светлый:
  ключевые слова `#d60066`, строки `#0f7a4d`, атомы `#7b3fe4`, числа `#b45309`; тёмных слябов нет.
- **Шрифты.** Archivo (заголовки, 800, плотный трекинг) и Martian Mono (код и моно-подписи) —
  семейства bun.com, взяты из Google Fonts как OFL; вордмарк «Squeal» — Fira Sans 700, только он.
  Все файлы self-hosted, внешних запросов нет.
- **JS без зависимостей** (`script.js`): табы код-карточек с ARIA и стрелками, copy (clipboard с
  фолбэком через `execCommand`), scrollspy нава, появление секций через IntersectionObserver с
  уважением к `prefers-reduced-motion`. Без JS страница читается целиком: reveal-классы ставит сам скрипт.

## Проверка

- `python3.15 -m squeal build` на демо-проектах со сниппетами → exit 0, ожидаемые `.erl`.
- `erl -pa … -eval` → ожидаемые значения.
- `node --check site/script.js` → синтаксис; DOM-прогон в jsdom: табы переключают `aria-selected` и
  `hidden`, copy берёт текст активной панели без номеров строк.
- `firefox --headless --window-size=1440,5400` и `390,2600` → вёрстка не ломается, обе ширины
  просмотрены глазами.
