Six rules,
baked into the compiler.

Each one is either a compile error in Python or a form Gleam would emit. squeal doesn't guess — it refuses, or it matches Gleam exactly.

01

Immutability

replaces mutation

No for, no while, no +=, no assignment to an index. Rebinding is allowed — the compiler names the new value X@1.

x = x + 1   # X@1 = X + 1
02

Expressions

replaces early returns

if and match end by assigning one variable. That assignment is the value of the branch.

match n:
    case 0:
        r = 0
03

Let it crash

replaces error codes

A match that matches nothing raises {case_clause, V} in the process. Exhaustiveness is a suggestion, not a requirement.

1> shapes:shift(nope, 3).
** exception error: no case clause
04

Patterns

replaces isinstance chains

Destructuring, constructor patterns, guards and or-patterns compile to the very patterns Gleam emits.

head, *rest = xs
case Point(x, y) if x > 0:
05

Comprehensions

replaces loops

List and dict comprehensions become Erlang comprehensions — generators, filters and nesting in the same order.

[x * 2 for x in xs]
# [X * 2 || X <- squeal_iter(Xs)]
06

Modules

replaces import trees

The module is the path: src/a/b/c.ee becomes a@b@c. Imports are Python imports; the BEAM does the rest.

from my.app.math import add
# → my@app@math:add(…)

squeal is a small language.
And it says no a lot.

Gleam is the reference for the semantics, Python for the syntax. Where the two disagree, squeal follows Gleam — and proves it with tests.

PropertysquealGleamPython
SyntaxPython 3.15ML-likePython
MutationNoNoYes
LoopsNoNofor / while
Pattern matchingYes, let it crashYes, exhaustivematch statement
TypesAnnotations as docsHindley–MilnerOptional hints
Compiles toBEAM, abstract formsBEAM, abstract forms—
Runtime dependencies00Interpreter + packages

Gleam 1.19 parity is enforced by 19 pairs of equivalent modules: both compilers must emit the same forms, compared after normalising line annotations. 104 tests in total, run with pytest.

Honest about the stage.
This is milestone one.

A compiler, a parity suite and a notebook. Types, static analysis and syntax beyond Python are not here yet — and the page says so.

Works today

  • doneCompiler from .ee to the BEAM Abstract Erlang forms, then compile:forms — the Gleam pipeline.
  • doneParity suite against Gleam 19 equivalence pairs, compared form by form.
  • doneJupyter notebook and persistent REPL Shell-mode cells over a live Erlang session.
